# Plan de Implementación: Rediseño Premium y Optimización de IA (v3.0 Beta)

Este plan detalla los cambios propuestos para auditar, modernizar y refinar visualmente la SPA **"UTNContenidos"** y optimizar la generación de contenidos mediante la API de Gemini, alineándolo con las directrices de diseño del Escuadrón de Excelencia.

## User Review Required

> [!IMPORTANT]
> **Accesibilidad del Docente (+50 años):** Se reemplazará el texto gris de bajo contraste y el glassmorphism excesivo sobre fondos de lectura por una interfaz de alta legibilidad, letras grandes (`text-base` como mínimo) y elementos interactivos sobredimensionados para evitar la fatiga visual.
>
> **Estructura del JSON de Gemini:** Se alterará ligeramente la estructura de respuesta que devuelve el backend (`api/gemini.js`) para incorporar sugerencias de diseño estético para las diapositivas (`disenoSugerido` e `iconoRepresentativo`). Esto requiere que el script frontend en `script.js` esté preparado para procesarlo sin romperse.

## Proposed Changes

### 1. Identidad Visual y Estética Premium ([style.css](file:///c:/Users/lsi/Documents/UTNContenidos/style.css))

Rediseñaremos la paleta de colores y el layout para lograr un diseño "Premium Minimalista" y de alta accesibilidad para adultos mayores.

#### [MODIFY] [style.css](file:///c:/Users/lsi/Documents/UTNContenidos/style.css)
*   **Ajuste de Tipografía y Contraste:** Cambiar el tamaño base del body de `16px` a `17px`. Reemplazar las variables de texto secundario por grises oscuros de alto contraste (`#2D3748` en lugar de `#57575f`) para cumplir con las normas de accesibilidad WCAG AA.
*   **Paleta Institucional Renovada:**
    *   `--ios-blue` y Azul UTN: `#0A2540` (Azul profundo espacial para textos principales) y `#0066CC` (Azul interactivo).
    *   Fondos limpios: `#F8FAFC` en lugar de grises sucios.
*   **Rediseño de Tarjetas:** Crear bordes ultra delgados con sombras difusas de profundidad (`box-shadow: 0 4px 30px rgba(0,0,0,0.02), 0 1px 3px rgba(0,0,0,0.05)`).
*   **Microinteracciones:** Agregar transiciones de rebote elástico a botones y hover de tarjetas (`transform: translateY(-4px) scale(1.01)`).

### 3. Optimización del Prompt de Gemini ([api/gemini.js](file:///c:/Users/lsi/Documents/UTNContenidos/api/gemini.js))

Mejorar las instrucciones del sistema para asegurar que Gemini genere planes pedagógicos sofisticados y diapositivas verdaderamente minimalistas.

#### [MODIFY] [api/gemini.js](file:///c:/Users/lsi/Documents/UTNContenidos/api/gemini.js)
*   **Reglas de Diseño Minimalista en el Prompt:**
    *   Instruir a la IA a **no saturar** las diapositivas de texto (máximo 3 puntos clave por slide, de no más de 12 palabras cada uno).
    *   Exigir un flujo pedagógico estructurado:
        1.  *Slide 1:* Portada institucional.
        2.  *Slide 2:* Hook o Pregunta disparadora (para captar atención).
        3.  *Slide 3 y 4:* Concepto núcleo simplificado (los pilares teóricos).
        4.  *Slide 5:* Analogía del mundo real o caso práctico regional (Delta/Campana).
        5.  *Slide 6:* Pregunta interactiva para el aula (fomentar participación).
        6.  *Slide 7:* Resumen y "Takeaway" (el concepto que deben recordar al salir).
*   **Ampliación del Esquema JSON:**
    *   Añadir `"disenoSugerido": "dos-columnas | lista-destacada | concepto-eje"` en cada slide para guiar el renderizado visual.
    *   Añadir `"icono": "emoji o clase lucide"` para dar soporte visual a cada tema.
*   **Refinamiento de Prompts de Imagen:** Forzar prompts en inglés optimizados para estilos profesionales (ej: *"Flat design illustration, corporate clean tech, blue color palette, professional"*).

## Verification Plan

### Automated Tests
*   `node api/gemini.js` (Simulación de Request de prueba para validar que el JSON retornado cumple la estructura extendida y es parsed localmente sin errores de sintaxis).

### Manual Verification
1.  **Auditoría de Contraste y Accesibilidad (Lighthouse):** Ejecutar inspección de accesibilidad en Chrome DevTools para garantizar contraste superior al 4.5:1 en todos los textos de la SPA.
2.  **Prueba de Flujo de Entrada:** Validar que el login y el buscador dinámico de temas respondan de forma instantánea y fluida.
3.  **Visualización de Diapositivas:** Generar una clase de prueba (ej: "Límites" en Análisis Matemático I) y verificar que las tarjetas de las diapositivas muestren la estructura minimalista sugerida y no bloques densos de texto.
