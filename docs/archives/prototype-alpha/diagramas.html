3. Flujo Funcional del Docente

El recorrido completo: ingreso, configuración, generación y exportación en menos de 6 clics.

sequenceDiagram
    participant P as Profesor (50+)
    participant S as SPA (script.js)
    participant G as GAS (app.md)
    participant V as Vercel (api/gemini.js)
    participant M as Gemini API

    P->>S: Ingresa Legajo + DNI
    S->>G: validarDocente (rate-limit + lockout)
    G-->>S: Token efímero + Dashboard (caché 1h)
    P->>S: (Opcional) ＋ Agregar tema a una materia
    S->>G: agregarTema (LockService)
    G-->>S: Tema persistido en hoja Temas
    P->>S: Elige Materia y Tema (2 clics)
    P->>S: Configurador iOS 27 (todo opcional)
    S->>G: obtenerPlantillas (hoja Plantillas BD)
    P->>S: Personaliza / guarda plantilla
    S->>G: obtenerContextoTema (RAG caché 6h)
    S->>V: generarClaseIA (Structured Outputs + config)
    V->>M: Prompt pedagógico + configuración
    M-->>V: JSON N slides + plan + notas
    V-->>S: Clase generada (fallback GAS si 405)
    P->>S: "Guardar en Google Slides"
    S->>G: exportarAGoogleSlides (LockService)
    G->>G: Crea Slides + Notas de Orador + registra historial
    G-->>S: URL de la presentación
    S-->>P: Modal éxito + Link directo
    P->>S: Historial (reciente/usado/archivado +15d)
    P->>S: "↩ Reabrir clase" (datosClase) / "📁 Carpeta"
    S->>G: actualizarHistorial (carpeta + datosClase)
